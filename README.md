# Ultrawide Black Bars

Ultrawide Black Bars / 带鱼屏视频去黑边 is a Manifest V3 browser extension for Bilibili video pages. It detects ultrawide 21:9 and 32:9 viewports and lets you keep the original aspect ratio, switch to crop-to-fill, or use ambient light on the side black bars.

## Install

1. Open your Chromium browser's extensions page.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select `/home/runner/work/ultrawide-black-bars/ultrawide-black-bars`.
5. Open a Bilibili video page and use the popup or `Alt+Shift+U` to cycle modes.

Keywords: ultrawide, black bars, 21:9, Bilibili.
